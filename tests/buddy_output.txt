=============================================
 Memory Management Simulator
=============================================
Modes:
  mode standard
  mode buddy
  mode cache

STANDARD mode commands:
  init memory <size>
  set allocator <first|best|worst>
  malloc <size>
  free <block_id>
  dump
  stats

BUDDY mode commands:
  init memory <size>   (size must be power of 2)
  malloc <size>
  free <block_id>
  dump

CACHE mode commands:
  cache init L1 <size> <block> <assoc>
  cache init L2 <size> <block> <assoc>
  cache access <address>
  stats

  mode vm
VM mode commands:
  vm init <pages> <page_size> <frames>
  access <virtual_address>
  stats

General:
